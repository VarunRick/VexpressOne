# 🚚 VExpress

A Full Stack Logistics Management System built using Spring Boot, React, MySQL, and JWT Authentication.

---

## 📌 Project Overview

VExpress is a logistics management platform designed to manage customers, employees, shipments, vehicles, and deliveries.

The application follows a modern Full Stack architecture:

React Frontend
↓
REST APIs
↓
Spring Boot Backend
↓
MySQL Database

---

## 🔒 Authentication Flow

1. Register User
2. Login
3. Receive JWT
4. Store JWT
5. Send JWT in Authorization Header
6. Access Protected APIs
